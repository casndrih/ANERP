# Papua New Guinea localisation
Defaults: PGK, country code PG, Pacific/Port_Moresby, English.

Never hard-code tax or payroll rates. Use effective-dated, versioned configuration for PAYE brackets/thresholds/rebates, superannuation rates and eligibility, GST treatment and employment/leave entitlements. Validate current rates, effective dates and reporting formats with PNG IRC, relevant superannuation funds and a qualified PNG accountant/payroll professional before production. Keep rule source, effective date, approver and version in audit history.

Do not claim IRC approval or live bank/fund integrations until implemented, tested and formally authorized.
