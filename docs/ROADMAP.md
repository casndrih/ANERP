# ANERP roadmap
1. Foundation: Laravel deployment, PNG defaults, dashboard and core module schema.
2. Security and tenancy: authentication, MFA, company/branch context, granular permissions, audit trail and tenant-isolation tests.
3. Operations: product catalogue, immutable stock ledger, warehouse balances, requisitions → approvals → purchase orders → goods receipts → supplier invoices, employee records, leave and attendance.
4. Payroll and finance: effective-dated PNG payroll configuration, PAYE/superannuation validation, payslips, double-entry journals, AP/AR, cashbook, bank reconciliation and period close.
5. Reporting and integrations: financial statements, inventory/procurement/payroll reports, CSV/XLSX/PDF exports, REST API, webhooks, POS, biometrics and banking adapters.
6. Production readiness: security review, penetration testing, restore drills, disaster recovery, load testing and user acceptance testing.
